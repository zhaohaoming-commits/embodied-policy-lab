# 数据来源与处理过程

## 原始来源

数据通过 ManiSkill 3.0.1 官方下载工具获取：

```powershell
python -m mani_skill.utils.download_demo PickCube-v1 \
  --output_dir data/maniskill/demos
```

下载包包含 motion planning、RL policy 和 teleoperation 三类演示。当前正式状态基线使用：

```text
data/maniskill/demos/PickCube-v1/rl/
trajectory.none.pd_joint_delta_pos.physx_cuda.h5
```

配套 JSON 元数据说明：

- `source_type`: `rl`
- `source_desc`: demonstrations generated by rolling out a PPO dense-reward policy
- 原始环境：`PickCube-v1`
- 原始 observation：`state`
- 控制模式：`pd_joint_delta_pos`
- 仿真后端：`physx_cuda`
- 并行环境数：1024
- 最大 episode 长度：50
- 原始成功 trajectories：997
- ManiSkill 数据生成 commit：`baab60ede2e89167c1b7aaed41a9aa8e690a9d1e`

这些数据不是本项目自行遥操作采集，也不能在README或简历中描述成自采数据。

## 本地预处理

原始压缩轨迹没有保存 observation，只保存动作和环境状态。我们使用环境状态在本地 CPU 后端重放并补回42维 state observation：

```powershell
python -m mani_skill.trajectory.replay_trajectory \
  --traj-path <raw-h5> \
  --save-traj \
  --obs-mode state \
  --use-env-states \
  --count 200 \
  --sim-backend physx_cpu \
  --num-envs 1
```

共请求200条，199条成功保存，一条重放失败并被工具剔除。生成文件：

```text
trajectory.state.pd_joint_delta_pos.physx_cpu.h5
```

本项目使用固定 seed 将199条 episode 打乱后划分为160条训练和39条验证。划分发生在窗口化之前，避免同一轨迹的相邻状态进入不同 split。

## 数据发布策略

官方数据和预处理数据均位于被 `.gitignore` 排除的 `data/`，不会上传GitHub。公开仓库只提供来源、版本、下载命令和预处理命令，保证合法且可复现。
